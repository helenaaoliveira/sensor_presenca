# Sensor de Presença

### Descrição da Atividade

Nesta atividade, foi desenvolvido no Tinkercad um circuito utilizando um sensor de presença (PIR), LED e Arduino. O código foi construído de forma progressiva, desde a configuração dos pinos até a leitura do sensor e o controle do LED. Ao detectar movimento, o sensor aciona o LED por 5 segundos; quando não há movimento, o LED permanece apagado.
